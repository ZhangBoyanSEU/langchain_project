**数据清洗是数据预处理中的关键环节，目的是提高数据质量，确保后续分析和建模的准确性。常用的方法可归纳为以下几类：**

# 缺失值处理
- 删除：直接删除含缺失值的行或列（适用于缺失比例极低的情况）。
- 填充：
  1. 用均值、中位数、众数填充数值型数据。 
  2. 用前向/后向填充（时间序列常用）。 
  3. 用模型预测填充（如回归、KNN）。 
- 插值：线性插值、多项式插值等，适合连续型数据。

# 重复值处理
- 完全重复的行直接删除。
- 部分字段重复时，根据业务规则保留一条（如保留最新记录）。

# 异常值检测与处理
- **统计方法**：3σ原则（超出均值±3倍标准差）、四分位距（IQR）法。
- **可视化方法**：箱线图、散点图识别离群点。
- **处理方法**：删除、替换为边界值、单独标记或使用稳健统计量（如中位数）。

# 数据类型转换
- 将字符串转为数值（如“123” → 123）。
- 将数值转为分类（如年龄分段）。
- 日期时间解析为标准格式。 

# 格式统一
- 文本大小写统一（如全部小写）。
- 去除空格、特殊符号。
- 统一单位（如 kg ↔ g、美元 ↔ 人民币）。
- 日期格式统一（如 YYYY-MM-DD）。

# 文本数据清洗
- 去除HTML标签、URL、表情符号。
- 分词、去除停用词（中文常用 jieba，英文用 NLTK）。
- 词干提取/词形还原。
- 正则表达式匹配替换特定模式（如手机号、身份证号脱敏）。

# 标准化与归一化
- **Z-score 标准化**：使数据均值为0，标准差为1。
- **Min-Max 归一化**：缩放到 [0,1] 区间。
- 适用于不同量纲的特征，避免模型偏向大数值特征。

# 处理不一致数据
- 同一实体不同写法（如“北京”、“北京市”）合并。
- 编码不一致（如 GBK 与 UTF-8）统一转换。
- 逻辑矛盾修正（如年龄为负数、结束时间早于开始时间）。 

# 特征工程辅助清洗
- 对长尾分布做对数变换。
- 离散化连续变量。
- 创建衍生特征（如从日期提取星期、月份）。

# 数据集成时的清洗
- 多源数据合并时，解决模式冲突、单位差异、冗余字段。
